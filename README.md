# Excel Practice
A collection of Excel exercises and business-analysis projects designed to strengthen practical spreadsheet and data-analysis skills.
# Topics Covered 
- Excel formulas and functions
- Data cleaning
- Sorting and filtering
- Conditional formatting
- XLOOKUP
- INDEX/MATCH
- SUMIFS and COUNTIFS
- IF/IFS statements
- Date and text functions
- PivotTables
- Charts and dashboards
- Power Query
- Data analysis
- Business and financial modeling
# Repository Structure
| Section | Focus | Skills |
|---|---|---|
| 01 Formulas | Excel fundamentals | IF, SUM, AVERAGE, COUNT |
| 02 Data Cleaning | Data preparation | Duplicates, formatting, text cleanup |
| 03 Lookups | Data retrieval | XLOOKUP, INDEX/MATCH |
| 04 Conditional Logic | Analytical formulas | IF, IFS, SUMIFS, COUNTIFS |
| 05 PivotTables | Data summarization | PivotTables, grouping, filtering |
| 06 Visualizations | Data presentation | Charts and dashboards |
| 07 Power Query | Data transformation | Importing, cleaning, transforming |
| 08 Business Analysis | Applied analytics | Business problems and reporting |
# Goal
The goal of this repository is to develop strong Excel skills for data analysis, reporting, and business decision-making.

The exercises become progressively more focused on realistic business scenarios rather than isolated formula practice.
