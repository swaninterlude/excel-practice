# Excel Practice
A collection of Excel exercises and business-analysis projects designed to strengthen practical spreadsheet and data-analysis skills.
# Topics Covered 
- Excel formulas and functions
- Data cleaning
- Sorting and filtering
- Conditional formatting
- XLOOKUP
- INDEX/MATCH
- SUMIFS and COUNTIFS
- IF/IFS statements
- Date and text functions
- PivotTables
- Charts and dashboards
- Power Query
- Data analysis
- Business and financial modeling
# Repository Structure
# Goal
The goal of this repository is to develop strong Excel skills for data analysis, reporting, and business decision-making.

The exercises become progressively more focused on realistic business scenarios rather than isolated formula practice.
